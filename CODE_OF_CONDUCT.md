# Code of Conduct

DevDoctor should be a practical, respectful project for Linux developers and maintainers.

## Expected Behavior

- Be direct and constructive.
- Keep criticism technical and specific.
- Assume good intent when asking for clarification.
- Respect that maintainers may decline changes that do not fit the project scope.
- Help keep issues reproducible and actionable.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Discriminatory language or behavior.
- Posting private information without permission.
- Repeated off-topic comments after maintainers redirect the discussion.
- Pressuring maintainers to run unsafe commands or merge unreviewed code.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues; block users; or restrict participation when behavior harms the project.

Report conduct concerns privately through repository maintainers. Do not use public issues for sensitive reports.
